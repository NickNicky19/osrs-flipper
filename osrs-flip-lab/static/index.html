Privacy and scope

No game credentials, plugin access, vendor APIs, premium-service calls or external web assets. The website never starts collection; collector.py is an explicit opt-in process that accesses only the configured public Wiki routes. This app listens only on 127.0.0.1. It is not designed for public hosting. Data lives in your local data folder; it is not encrypted by this starter.

To prevent silent history changes, this version has no edit/delete button. Incorrect entries require a reviewed correction or restoration workflow; do not enter offsetting fake fills.
